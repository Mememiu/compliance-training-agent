# 反腐败微课接入设计

2026-09-09。按用户已确认的前两课流程，将终版《多停一秒·廉洁有度》接入反腐败与商业道德，而不是另建课程或改版视觉。

## 学习流程

依次确认 ac-1、ac-2、ac-3 文字课，进入费用、利益冲突、礼品三段情境。每段必须听完对话、核对四条记录、选择合适回应、查看复盘并明确完成。三段均成功保存后，模块完成。文字占 50%，微课占 50%。旧测验成绩保留为历史，不自动免除新微课。

## 实现边界

复用现有课程注册表、iframe 容器和顺序门禁。独立 integrity_learning、消息通道和存储键，避免三门微课串进度。原终版 source、preview、插画及动画保持不变；生产入口由固定源哈希与可验证补丁生成。生产说明更新为真实接入流程，制度示例与免责声明不变。

与直接改写原引擎相比，采用独立适配器保留终版可复现性。恢复异常保护原记录；保存失败不计完成，可重试。复习或重置练习不撤销已获得的模块完成记录。

## 验收

单元测试覆盖顺序、迁移、隔离、持久化；桌面和移动端真实点击全流程，检查断点继续、错误路径、旧课程回归。独立审查后推送 main 和现有 gh-pages，核验远程提交和线上资源。
