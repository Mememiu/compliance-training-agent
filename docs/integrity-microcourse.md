## 内容与流程

依据 `src/data/courses.ts` 中 `anti-corruption` 的三课原文编写虚构教学对话。本页是实践练习，不代替原文全部知识点和正式测验，不写入培训室成绩。

| 原课时 | 场景 | 学习任务 |
| --- | --- | --- |
| ac-1 反贿赂法律框架与红线 | 双人项目工位，陈卓作为画外学习者 | 9 句对话，核对咨询费真实用途，暂停可疑付款并记录反馈 |
| ac-2 利益冲突识别与管理 | 完整采购评审会议室 | 10 句对话，在评分前说明亲属关系、申报与回避 |
| ac-3 廉洁从业行为准则 | 礼品工位，许宁通过耳机与陈卓通话 | 10 句对话，核对礼品目的、累计记录、退还与报备 |

每段依次为：开场 → 逐句对话 → 逐项核对四条记录 → 选择 → 反馈 → 复盘要点 → 完成本段。每段有三种选择，其中两种合理路径、一种需要返回重选。完成复盘后才能解锁下一段；当前段开始后，不能切换到其他段来跳过当前情境。已完成段在可访问时允许回看，不降低已完成进度。

拒贿插画只在第一段选择得到认可后的解析与复盘出现，避免练习前用画面提示答案。回看对话只显示已经阅读的部分。不上传个人数据。

### 断点续学

使用独立的 localStorage 键 `duoting-integrity-v1-progress`，结构版本为 1，仅保存当前情境、步骤、已读句序号、勾选记录序号、选择键、通关标记和回顾状态。每次学习状态变化后保存，不记录姓名、对话正文或业务信息，也不计作培训室成绩。

再次打开有效记录时显示“继续学习”，确认后恢复原步骤；“重新开始”须经确认，只清除本课记录，不影响其他课程。损坏、不兼容或步骤不一致的记录安全重置并解释原因。读取／写入失败时提示本次无法保留进度，但不阻断学习。

续学限同一浏览器与同一文件／地址；更换设备、清理浏览器数据或浏览器禁用本地存储时，不承诺恢复。离线文件下存储行为依浏览器而异，代码做失败降级，未宣称跨浏览器已实测。共用设备可通过重新开始清除本课记录。

## 替换与构建接口

- `scripts/prepare-integrity-assets.mjs`：源文件名与原始像素裁框。可选第一个参数替换素材根目录。原始 JPG 是本地构建输入，不需要浏览器访问。
- `src/data/integrity-scenes.mjs`：每张图片的固有尺寸及热点百分比坐标 `x/y/w/h`。图片和热点共享同一容器，替换美术后必须同步更新。
- `src/data/integrity-stories.mjs`：角色、29 句对白、证据记录、九种选择反馈及制度提醒。
- `src/integrity/course.html`、`course.css`、`course.js`：独立页面模板、UI 和状态机，没有读取第二课 HTML 的依赖。
- `scripts/build-integrity-microcourse.mjs`：内嵌上述内容，输出 `public/microcourses/integrity-preview/index.html`。

```sh
node scripts/prepare-integrity-assets.mjs
node scripts/build-integrity-microcourse.mjs
./node_modules/.bin/tsx --test tests/integrity-stories.test.ts
npm run build
```

最终 HTML 为 UTF-8 单文件，约 484 KB。可以单独复制后打开；图片、CSS、JavaScript 无外部资源请求。中文字体使用本地回退栈，没有假称内嵌字体。初始插画同时作为静态 HTML 回退嵌入，因此在数据中重复一份，这是有意的无 JavaScript 容错；互动仍需要 JavaScript。
