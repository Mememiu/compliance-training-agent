# 第二课接入设计（2026-09-09）

用户要求第二课按第一课相同逻辑接入，并将完成版本推送 GitHub，此为本轮已确认的流程依据。

源文件为 `多停一秒_尊重有界_V1.html`，内容为言语边界、平等机会、支持求助三段情境，映射培训室的“劳动合规与职场行为”（labor-compliance），而不是反腐败课程。

两课时文字显式顺序阅读 → 《多停一秒·尊重有界》 → 依序听取三段对话、选择被认可的回应并确认要点 → 模块完成。旧五题保留题库，不再是本课程必修路径。第一课及反腐败考核保持原规则。

源导出无持久化。以独立 bridge 补充当前情境、对话位置、回应、阶段及已获得完成记录；刷新恢复，重播不撤销已完成情境。数据保存在本地浏览器，使用与第一课不同的命名空间，不增加后台和遥测。只有成功落盘的合格回应能回传完成。

宿主沿用第一课的 origin/source/channel/token 和明细校验；只接受三个已知情境、原作者认可回应和顺序完成。读文字占 50%，三段微课占 50%。旧成绩另存历史，不当作新版微课通关。保存失败提示和重试。

不修改微课源项目和故事内容，不改插画/动画/法务文案。保留源导出的教学练习及正式制度待确认提示，不宣称经过新增法律审查。复用终版静态 HTML，不重新设计课程。

验证后推送本轮及上一轮尚未推送的第一课接入到当前 GitHub 仓库；不做破坏历史的 force push。检查现有 Pages 发布方式后沿用已有方式更新发布版本。
